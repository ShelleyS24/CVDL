# OpenCV Computer Vision Demos

This module contains GUI-based demos for classical computer vision tasks implemented with OpenCV and PyQt.

## Technical Scope

- Camera calibration using chessboard images
- Augmented reality projection
- Stereo disparity estimation
- SIFT keypoint detection and feature matching

## Technologies

- Python
- OpenCV
- NumPy
- PyQt
- Matplotlib

## Project Structure

```text
opencv-computer-vision-demos/
├─ main
├─ qtUI.ui
├─ question1.py
├─ question2.py
├─ question3.py
├─ question4.py
└─ requirements
```

## Run

```bash
cd opencv-computer-vision-demos
python main
```

This module requires the corresponding image folders extracted from `Image.zip`.

Expected local image folders:

```text
Q1_Image/
Q2_Image/
Q3_Image/
Q4_Image/
Q5_image/
```

Large image archives are excluded from Git tracking.
